Machine learning and research

  • Micro-RAG over an RDF Knowledge Graph

    Retrieval-augmented question answering built from scratch: a TF-IDF retriever over RDF triples feeds a compact encoder-decoder Transformer (256-dim, 3+3 layers, 8 heads) written in PyTorch, with no pretrained weights. One shared trunk is trained on four tasks: text to triples, triples to text, grounded QA and triple-consistency checking.

    • PyTorch
    • Transformers
    • RAG
    • scikit-learn

  • German SME Bank Transaction Classification

    Leakage-safe reproduction of a published SME transaction-categorisation pipeline (Aluffi et al., 2025) adapted to German text and 37 classes. GermanFinBERT scored 0.649 ± 0.027 accuracy against 0.612 ± 0.025 for FinBERT across five seeds, with temperature scaling and confidence-based routing of low-confidence predictions to manual review.

    • Hugging Face
    • FinBERT
    • PyTorch
    • Calibration

  • SVD-Based Collaborative Filtering

    Recommender system on MovieLens 100K and 1M. Truncated SVD at k=10 reaches an RMSE of 0.8812 against 1.0447 for a global-mean baseline, and SGD matrix factorisation reaches 0.8710. On MovieLens 1M the best rank is k=20 with an RMSE of 0.8943.

    • Python
    • NumPy
    • Matrix factorisation

  • Respiratory Waveform Forecasting

    BiLSTM with Bahdanau attention that predicts 15 seconds of the nasal-pressure waveform from 20 seconds of physiological signal read from EDF files. Includes filtering, resampling to 32 Hz, sliding-window inference, CSV and EDF export, and GPU execution with CPU fallback.

    • PyTorch
    • BiLSTM
    • Attention
    • Time series
